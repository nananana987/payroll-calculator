# 給与計算・手取り逆算アプリ（協会けんぽ静岡支部・令和8年分／令和9年分税額表対応）

支給額から社会保険料・雇用保険料・源泉所得税・手取り額を計算し、さらに目標手取り額から必要な支給額を逆算できるシングルファイル Web アプリです。上部の切替ボタンから、**令和8年分**と**令和9年分**の源泉徴収税額表（月額表）をワンクリックで切り替えられます。

## 主な機能

- **令和8年分／令和9年分 源泉徴収税額表（月額表）切替**
  - ヘッダーの切替ボタンで順計算・逆算・税額表リファレンスすべてに即座に反映
- **支給額 → 手取り計算（順計算）**
  - 健康保険料・介護保険料（40〜64歳）・厚生年金保険料・子ども・子育て支援金・雇用保険料・源泉所得税を計算
  - 控除内訳の社会保険料等は保険料額表と合わせた小数点第2位表記、合計・手取りは端数処理後の整数表記
- **手取り額 → 支給額逆算（逆計算）**
  - **パターンA**：現在の標準報酬月額を固定して逆算
  - **パターンB**：標準報酬月額も自動計算して逆算
  - 両パターンの必要支給額・控除合計を並べて比較可能
- **料率・月額表リファレンス**
  - 協会けんぽ静岡支部 令和8年度 50等級一覧、令和8年分／令和9年分 源泉徴収税額表（月額表）クイック検索

## 適用基準・出典

- 健康保険・介護保険・子ども・子育て支援金・厚生年金：[協会けんぽ静岡支部 令和8年度保険料額表](https://www.kyoukaikenpo.or.jp/assets/R8_22shizuoka.pdf)（健康保険 9.61%・介護保険 1.62%・子ども・子育て支援金 0.23%［令和8年4月分〜］・厚生年金 18.300%）
- 雇用保険：[厚生労働省 令和8年度 雇用保険料率のご案内](https://www.mhlw.go.jp/content/001692566.pdf)（一般の事業 労働者負担 5/1,000）
- 源泉所得税：[国税庁 令和8年分 給与所得の源泉徴収税額表（月額表）](https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2026/data/01-07.pdf) ／ [国税庁 令和9年分 給与所得の源泉徴収税額表（月額表）](https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2027/data/01-07.pdf)
